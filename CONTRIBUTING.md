# Contributing to CampusConnect Notices

1. Fork the repository.
2. Create a focused feature branch.
3. Follow WordPress coding conventions and sanitise/escape output appropriately.
4. Test the plugin on a local WordPress installation.
5. Commit with a clear message.
6. Open a pull request describing the change.
7. Address reviewer comments before merging.

Because this plugin extends WordPress, changes must remain compatible with the project's GPL licensing requirements.
