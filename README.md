# CampusConnect Notices

CampusConnect Notices is a WordPress plugin developed for SWE 404 Module 8. It extends WordPress with a departmental notice feature.

## Features

- Registers a custom `campus_notice` post type.
- Adds an administration menu for notices.
- Supports title, editor and custom fields.
- Exposes notices through the shortcode `[campus_notices]`.
- Displays the five most recent published notices.
- Uses WordPress escaping functions for output.
- Declares GPL-2.0-or-later licensing to remain compatible with the course platform model.

## Installation

1. Copy the `campusconnect-notices` directory into `wp-content/plugins/`.
2. Activate **CampusConnect Notices** from the WordPress Plugins page.
3. Create notices under **Campus Notices**.
4. Add `[campus_notices]` to a page or post.
