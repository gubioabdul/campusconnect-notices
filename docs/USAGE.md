# CampusConnect Notices Usage

1. Copy the plugin into `wp-content/plugins/campusconnect-notices/`.
2. Activate **CampusConnect Notices** from the WordPress Plugins screen.
3. Create notices using the **Campus Notices** post type.
4. Place `[campus_notices]` in a page or post to display recent notices.
